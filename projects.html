05 / Data pipeline & MCP integration

Fresher Job Radar — Multi-Source Aggregator & MCP Server

personal project

A continuously-running pipeline that sweeps five job sources across every city × role combination in Tamil Nadu and Karnataka (plus Remote), filters for genuinely fresher-appropriate roles, and exposes the results two ways: a live web dashboard and a natural-language-queryable MCP server.

  • Five collectors — Naukri, LinkedIn, Internshala, Ashby, and Greenhouse/Lever career pages — each wrapped in a per-source rate-limit budget and circuit breaker so a string of errors pauses that source instead of risking a ban.
  • A fresher/experience filter reads the title, experience field, and full description to classify each listing MATCH / REJECT / UNKNOWN, then a dedup pass merges duplicate postings across sources by normalized company + title + location.
  • A bounded "deep research" pass opens each surviving listing's real posting page — plain HTTP first, falling back to headless Playwright only when the page looks JS-rendered — to pull the full description, a skills list, salary, and application deadline.
  • Every new company gets its real official website resolved and cached (not just its job-board listing page), so results link somewhere useful.
  • A Flask dashboard streams live scrape stats over Server-Sent Events — per-source budgets, circuit-breaker state, and a filterable results table.
  • The whole database is also exposed read-only through a custom MCP server — Claude Desktop can answer "show me fresher Python jobs in Chennai" directly from the live data.
